# මගේම AI - Simple Q&A Chatbot

Pure Python chatbot. No external libraries needed.

## How to run

```bash
python3 chatbot.py
```

## Add more questions & answers

Open `knowledge/qa.json` and add new entries like this:

```json
"your question": "the answer"
```

## Features

- Simple question-answer matching
- Supports Sinhala and English
- No internet or extra packages required
