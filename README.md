# මගේම AI - Simple Q&A Chatbot

Pure Python + Web version. No external libraries needed.

## Files
- `chatbot.py` → Terminal version (TF-IDF + Fuzzy)
- `knowledge/qa.json` → Questions & Answers (770+)
- `index.html` → **Web page** (open in browser to chat)

## How to run (Terminal)
```bash
python3 chatbot.py
```

## How to use Web version
Just open `index.html` in any browser (Chrome / Firefox / Edge).
No server needed.

## Online hosting
You can upload `index.html` to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting

## Add more Q&A
Edit `knowledge/qa.json`:
```json
"your question": "the answer"
```
